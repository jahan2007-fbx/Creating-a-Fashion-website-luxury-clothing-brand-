# Myoo

**AI-powered custom clothing design**

Myoo is an experimental web application that explores how generative AI can be used to create personalized clothing designs. Users describe what they want (or upload inspiration), and the system generates unique garment concepts that can be further refined.

> This is an early-stage prototype / experiment in AI-assisted fashion design.

---

## Features

- Text-to-garment generation (describe a design and get AI concepts)
- Image-to-design (upload inspiration images)
- Basic garment customization (color, style, fit preferences)
- Preview of generated designs
- Simple user flow focused on experimentation
